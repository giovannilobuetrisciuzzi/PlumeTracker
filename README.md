# PlumeTracker
This is MATLAB-based application designed to estimate and track the velocity of gas plumes, volcanic fumaroles, and diffuse emissions from video files. The software features an interactive GUI for spatial calibration, ROI polygon selection, and real-time visualization. It supports a dual-engine Optical Flow workflow: RAFT (Deep Learning) for high-accuracy tracking of complex turbulence using GPU acceleration, and Farneback (Traditional Computer Vision) for lightweight and faster CPU processing. The pipeline includes spatial median filtering, temporal directional persistence checks, and adaptive morphological cleaning to isolate fluid motion and eliminate background noise. Results, including mean velocity, standard deviation, peak velocity, directional vector components, and the orthogonal cross-section width, are displayed in real time and automatically exported to CSV.
